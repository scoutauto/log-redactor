Log Redactor

A small, free, open-source tool that scrubs secrets out of log files before you paste them into a ticket, chat, or bug report.

What it removes

  • AWS access key IDs (AKIA/ASIA) → [REDACTED:aws_key]
  • password=, secret=, api_key=, token= values → [REDACTED]

Usage

python3 redact.py app.log > app.redacted.log

Tests

python3 test_redact.py   # 8 tests
